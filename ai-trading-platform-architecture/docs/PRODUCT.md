# المنتج — مساعد تداول خاص بالاشتراك

> وثيقة المنتج التجاري. للتفاصيل التقنية راجع `ARCHITECTURE.md`، ولمبررات القرارات راجع `DECISIONS.md`.

## 1. ما هو هذا المنتج

**مساعد تحليل واتخاذ قرار خاص، يُباع باشتراك شهري، ويُسلَّم عبر بوت تيليجرام عربي بالكامل.**

ليس منصة عامة، ولا موقعاً يسجّل فيه أي شخص. الوصول مغلق ومربوط بالاشتراك.

| العنصر | القرار |
|---|---|
| الواجهة | بوت تيليجرام (عربي بالكامل) |
| الويب | لوحة تحكم للمالك فقط — لا تسجيل عام |
| الهوية | `telegram_id` — لا كلمات مرور للعملاء |
| المخرجات | **إشارات وتحليل فقط** — لا تنفيذ صفقات |
| مفاتيح API للعملاء | **لا تُجمع ولا تُخزَّن إطلاقاً** |
| الدفع | يدوي/أكواد ترخيص الآن، مع طبقة مزوّد قابلة للتوسع |

### لماذا "إشارات فقط"؟

قرار تجاري وأمني مقصود (راجع `DECISIONS.md #12`):

- لا نحتفظ بمفاتيح تداول للعملاء، فلا يوجد ما يُسرق ذو قيمة مباشرة.
- المسؤولية القانونية عن التنفيذ تبقى على العميل.
- التزام مُرمَّز في الأنواع: واجهة `MarketDataSource` **لا تحتوي أصلاً** على دالة لإرسال أمر — لا يمكن تنفيذ صفقة عن طريق الخطأ.

## 2. شخصية النظام — كيف "يفكر" البوت

الهدف ليس كثرة الصفقات، بل **الجودة + إدارة المخاطر + الاستمرارية**.

| المبدأ | كيف طُبِّق فعلياً في الكود |
|---|---|
| لا يدخل بدون سبب قوي | `minConfluence = 52`، مُعايَر فوق الضجيج العشوائي (p99 = 47) |
| يعرف متى ينتظر | `wait` و `reject` نتائج ناجحة، وليست أخطاء |
| يرفض الفرص الضعيفة | 12 بوابة فيتو مرتبة، أول بوابة تفشل تحدد الحكم |
| يحمي رأس المال أولاً | سقف مخاطرة 2%، سقف حجم مركز 25% من المحفظة |
| لا يطارد السعر | إذا ابتعد السعر >4 ATR عن مستوى الإبطال ⇒ `WAIT_BETTER_PRICE` |
| يتعلم من نتائجه | حلقة معايرة تُقلّل الثقة حيث كان النظام مبالغاً فيها |
| يحلل أخطاءه | `deriveLessons()` يستخرج دروساً عربية قابلة للتنفيذ |

### الصدق مع العميل

- كل قرار يُحفظ في قاعدة البيانات — بما فيه **الرفض**. هذا هو المقام الصادق لأي نسبة نجاح نعلنها.
- الاحتمالية المعروضة تقدير أولي حتى تتراكم نتائج حقيقية، ولا تُقدَّم أبداً كإحصاء مُثبَت.
- عند التتبع، إذا لامست الشمعة الهدف والوقف معاً، **نفترض الوقف أولاً**. الافتراضات المتفائلة هي كيف يُعلن البائعون نسب نجاح لا يحققها عملاؤهم.
- كل إشارة تحمل إخلاء مسؤولية صريحاً.

## 3. الخطط والاشتراكات

الخطط **بيانات وليست كوداً** — إضافة خطة جديدة = صف في جدول `plans`، بدون أي نشر جديد.

| الميزة (`features`) | المعنى |
|---|---|
| `maxSymbols` | عدد العملات المشمولة (`-1` = الكل) |
| `onDemandAnalysisPerDay` | حد `/تحليل` اليومي (`-1` = بلا حد) |
| `dailyReports` / `weeklyReports` / `monthlyReports` | صلاحية التقارير |
| `prioritySeconds` | أسبقية استلام الإشارة |
| `fullAnalysisBreakdown` | التحليل المفصّل مقابل الملخص |
| `customRisk` | تخصيص نسبة المخاطرة |

مثال مقترح (basic / pro / vip) — الأسعار يحددها المالك:

| | basic | pro | vip |
|---|---|---|---|
| العملات | 3 | 10 | الكل |
| تحليل يومي عند الطلب | 5 | 25 | بلا حد |
| التقارير | يومي | يومي + أسبوعي | الكل |
| التحليل المفصّل | ✗ | ✓ | ✓ |

### حماية العميل الدافع

`featuresSnapshot` يُخزَّن على الاشتراك وقت الشراء. تعديل خطة لاحقاً **لا يُخفّض** عميلاً دافعاً بأثر رجعي.

### دورة حياة الوصول

```
/بدء ──> pending ──(دفع/كود)──> active ──> expiring_soon ──> expired
                                   │
                          المالك: pause / suspend / ban
```

قواعد مُختبَرة (14 اختبار في `entitlements.test.ts`):

- **الحظر يسبق الفوترة** — لا نطلب الدفع ممن نرفض خدمته.
- **الإلغاء يحترم المدة المدفوعة** — الوصول مستمر حتى نهاية الفترة.
- **الإيقاف المؤقت لا يحذف التاريخ** — `pausedAt` يمنع الوصول ويحفظ السجل.

## 5. الأمان وحماية الأصول

| الخطر | الإجراء |
|---|---|
| تسريب توكن البوت | من متغيرات البيئة فقط، ولا يُسجَّل في اللوغ |
| تزوير الـ webhook | تحقق `secret_token` بمقارنة **زمن ثابت** قبل قراءة الجسم |
| تسريب قاعدة البيانات | جلسات المالك وأكواد الترخيص تُخزَّن **مُجزَّأة** (SHA-256) فقط |
| سرقة مفاتيح العملاء | لا توجد مفاتيح عملاء أصلاً |
| اختراق حساب المالك | جلسة 8 ساعات، أدوار `owner`/`support`، سجل تدقيق لكل إجراء |
| مشاركة الاشتراك | ربط بـ `telegram_id` + مراقبة الاستخدام في `usage_events` |
| بيانات سوق فاسدة | `validateCandles` يرفض الشموع غير المنطقية قبل وصولها للعقل |
| تعطل منصة | 3 مصادر بيانات + قاطع دائرة (circuit breaker) |

**حماية الكود:** المنطق الحسّاس (المعايرة، الأوزان، عتبات القرار) يعمل على الخادم فقط ولا يصل للعميل إطلاقاً.
