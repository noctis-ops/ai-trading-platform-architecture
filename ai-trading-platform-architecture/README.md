# مساعد التداول الخاص — Private Trading Assistant

بوت تيليجرام عربي يقدّم تحليلاً وإشارات تداول باشتراك شهري.
**إشارات وتحليل فقط — لا ينفّذ صفقات ولا يحتفظ بمفاتيح العملاء.**

> ## 📘 [اقرأ الوثيقة المرجعية الرسمية: `docs/MASTER.md`](docs/MASTER.md)
>
> هي المرجع الوحيد للمشروع: المعمارية، المبادئ الحاكمة، حالة التنفيذ،
> المراحل المتبقية، ودليل المطوّر. **أي تطوير يخالفها مرفوض.**

## البدء السريع

```bash
npm install
cp .env.example .env          # املأ القيم
npm run db:migrate            # إنشاء الجداول
npm run admin seed            # الخطط والعملات الافتراضية
npm run admin create-admin owner@example.com 'كلمة-مرور-قوية'
npm run dev
```

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm test` | 44 اختباراً (منها 12 على قاعدة بيانات حقيقية) |
| `npm run typecheck` | فحص الأنواع |
| `npm run lint` | فحص النمط |
| `npm run build` | بناء الإنتاج |
| `npm run calibrate` | دراسة معايرة عتبات القرار |
| `npm run admin` | أدوات المالك (خطط، أكواد، عملاء، إحصاءات) |
